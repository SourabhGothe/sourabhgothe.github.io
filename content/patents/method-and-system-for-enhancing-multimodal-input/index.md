### Abstract

A method and user equipment (UE) for enhancing multimodal input content is disclosed. The UE obtains text-blocks associated with multimodal input and determines a plurality of features for each of the text-blocks using a natural language processing (NLP) model and a neural network (NN) model. The system identifies usage patterns based on historical data, then generates personalized text with emoticons based on context and user preferences. The UE inserts personalized emoticons based on the context of text-blocks and the lingo of each word using a user lingo database, eliminating manual corrections and improving readability.
