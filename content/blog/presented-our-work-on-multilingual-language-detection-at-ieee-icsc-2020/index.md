The paper **"Language Detection Engine for Multilingual Texting on Mobile Devices"** was presented at the **14th IEEE International Conference on Semantic Computing (ICSC 2020)** in San Diego, California.

The work introduces a lightweight, real-time language detection engine that identifies the user's active typing language on-the-fly — eliminating the need to manually switch keyboard languages during multilingual conversations. The system is optimized for on-device execution on smartphones, with low latency and a small memory footprint.

**Authors:** Sourabh Vasant Gothe, Sourav Ghosh, Sharmila Mani, Bhanodai Guggilla, Ankur Agarwal, Chandramouli Sanchi — developed at **Samsung R&D Institute India – Bangalore**.
