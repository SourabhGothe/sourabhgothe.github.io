The paper **"Real-Time Optimized N-Gram for Mobile Devices"** was published at the **13th IEEE International Conference on Semantic Computing (ICSC 2019)**.

The work presents a highly optimized, lightweight N-gram language model engineered specifically for texting engines running on resource-constrained mobile devices. The approach achieves significant reductions in memory footprint while preserving high correction accuracy and next-word prediction quality — making it well-suited for production deployment on smartphones.
