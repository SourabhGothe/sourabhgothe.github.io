Two patent applications covering novel **Romanized Abugida text input methods** were filed with the **Indian Patent Office** in December 2019.

The inventions address the challenge of enabling fast, accurate, and intuitive text input for Abugida-script languages — such as Bengali, Hindi, Kannada, and Thai — using Romanized characters on touch-screen keyboards. The disclosures propose optimized disambiguation and prediction algorithms designed to improve typing speed and accuracy on resource-constrained mobile devices.

This early-stage intellectual property work would later form the basis for a formally **granted Indian patent** in 2025.
