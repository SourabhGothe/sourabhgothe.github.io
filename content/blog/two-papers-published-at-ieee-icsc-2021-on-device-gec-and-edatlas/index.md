Two research papers were published at the **15th IEEE International Conference on Semantic Computing (ICSC 2021)**:

**1. "An Efficient System For Grammatical Error Correction On Mobile Devices"**
A hybrid, lightweight GEC pipeline combining a spell-checker, a Deep Neural Network correction model, an N-gram language model, and a rule-based corrector — all optimised for real-time on-device inference on smartphones. The system is designed to correct grammatical errors without relying on cloud connectivity.
*Authors: Sourabh Vasant Gothe, Sushant Dogra, M. Chandra, Chandramouli Sanchi, Barath Raj Kandur Raja.*

**2. "edATLAS: An Efficient Disambiguation Algorithm for Texting in Languages with Abugida Scripts"**
An efficient algorithm that improves touch-screen text input accuracy for Abugida-script languages by resolving ambiguities that arise from the many-to-one mapping between Romanized keystrokes and Abugida characters.
*Authors: Sourav Ghosh, Sourabh Vasant Gothe, Chandramouli Sanchi, Barath Raj Kandur Raja.*

Both papers were developed at **Samsung R&D Institute India – Bangalore (SRIB)**.
